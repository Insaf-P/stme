# STME — Hello Elementor Child Theme

## Requirements
- Hello Elementor theme (free, from Elementor)
- Elementor plugin (free) or Elementor Pro

## Installation
1. Install & activate Hello Elementor theme from Appearance → Themes → Add New
2. Upload stme-elementor-child/ to /wp-content/themes/
3. Activate STME — Hello Elementor Child from Appearance → Themes

## Elementor Pro — Custom Header & Footer
If you have Elementor Pro:
1. Go to Elementor → Theme Builder → Header → Add New
2. Build your header there, or use the header.php override already included
3. Same for Footer → Theme Builder → Footer

## Without Elementor Pro
The theme ships with header.php and footer.php overrides that display the
STME nav and footer on all pages automatically.

## Page Setup
Create pages in WordPress and edit them with Elementor.
Set each page template to "Elementor Canvas" (full-width) or "Elementor Full Width".

For the home page: Settings → Reading → set a static front page.
